# Web link Embed View

In document mode, select a web link iframe embed and set **Height (px)** in its
toolbar. Enter a whole number of at least 100 pixels, then press Tab or click away
to apply it. Increase the height as needed to show more of the website. There is
no upper height limit.

The embed container stays fixed at the configured height, regardless of the
website's content. The height is saved with the embed. Clear the field to restore the website
provider's default height. Edgeless embeds continue to use their canvas bounds.

This sets the iframe viewport height manually; it does not detect the embedded
website's full content height. Websites that block embedding still cannot be
displayed.
